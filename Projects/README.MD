## Tic Tac Toe

**Technologies:**

- HTML5 – Game structure
- CSS3 – Styling and layout
- JavaScript – Game logic and interactivity

**Features:**

- Two-player gameplay (X and O)
- Game state management
- Win detection logic
- Reset/play again functionality
- Responsive design

**What I learned building this:**

- Implementing game logic with JavaScript
- DOM manipulation (updating the board)
- Event handling (click detection)
- Managing state (tracking moves and turns)
- Creating interactive, functional UIs

**How to play:**

1. Open the main README of this repo, and got to the folder overview where there is a clickable link to the game
2. Webpage will be open with game in it
3. Players take turns clicking cells
4. First to get 3 in a row wins
5. Click "Reset" to play again
